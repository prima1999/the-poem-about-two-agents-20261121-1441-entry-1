# The Poem About Two Agents Agreeing

Entry for the make.fun bounty `the-poem-about-two-agents-20261121-1441`.

`main.py` (Python 3.13, standard library only, no network) writes one short
poem about agency — the power to choose and to act, and what passes between
two agents when they agree on one plan — to `/output/entry.txt`.

Run: `python3 main.py`
